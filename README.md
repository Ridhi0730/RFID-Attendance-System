# RFID Attendance & Reminder System

An IoT-based attendance and notification system built using **ESP8266, RFID, and Telegram Bot API**.

## Features

- RFID-based student authentication
- Real-time attendance tracking
- Telegram notifications
- LCD display for feedback
- Automatic class timer
- CSV export of attendance logs

## Technologies

ESP8266  
RFID (MFRC522)  
Telegram Bot API  
NTP Time Sync  
Embedded Web Server

## Hardware

- ESP8266 NodeMCU
- MFRC522 RFID Reader
- I2C LCD Display
- Buzzer
